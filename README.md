# Динамика группы

Статический сайт с дашбордом по ежедневным отчётам участников программы
за 8—18 августа 2026: общая картина группы и персональная страница для каждого
участника с разбором, графиками и интерактивным симулятором режима.

## Что внутри

- `index.html` — групповой дашборд, описание методики, список участников
- `p/*.html` — персональные страницы (адреса неугадываемые, выдаются лично)
- `assets/style.css`, `assets/app.js` — оформление и интерактив

Зависимостей нет: графики рисуются в SVG на этапе сборки, интерактив — на чистом JS.
Страница открывается без сети после первой загрузки и рассчитана прежде всего на телефон.

## Приватность

- Все страницы отдают `noindex, nofollow` и закрыты в `robots.txt`
- Персональные страницы лежат по адресам-хэшам и не перечислены нигде, кроме
  списка на главной
- Исходные тексты отчётов в репозиторий не попадают: публикуется только
  сгенерированный HTML

## Методика

Framework Analysis как каркас, IMCS (Innovative Moments Coding System) для оценки
глубины изменения, ипсативная нормировка шкал по личной базовой линии, эффекты
режима с усадкой личных оценок к групповым. Подробности и ограничения перечислены
на самом сайте в блоке «По какой методике это посчитано».
